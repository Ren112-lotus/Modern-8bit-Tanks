# Modern-8bit-Tanks の車両制作

写実の4面図を先に制作し、その画像を元にゲーム用の車体・砲塔を作る。ゲーム内では既存の低解像度ドット絵と独立した車体・砲塔の回転に合わせる。ユーザー指定の型式、時期、塗装、対象範囲を優先する。

## ゲーム内アートの品質基準

新規制作・改修では、[M48A1・M48A3の同縮尺比較](references/m48-quality-benchmark.png) の `AFTER` を、世界観と描き込みの基準にする。対象車両の形状や塗装は、その型式・時期の実車資料に従う。

- **実車の比率と重量感**を優先する。車体の長さ・幅・高さ、砲塔の載り方、砲身の張り出しを実車写真と見比べる。車体が寸詰まりに見えたり、砲塔やキューポラだけが大きく見えたりする場合は、細部を増やす前にシルエットを整える。
- **マットな塗装と素材の明暗差**で形を読む。広い装甲面は低解像度で読めるまとまりを保ち、履帯・転輪・グリルは暗部と控えめなハイライトで分ける。鋳造肌や土汚れは濃淡を抑え、戦闘中の表示サイズで主な輪郭が読み取れるようにする。
- **型式差を形で出す。** M48の例では、A1の低いキューポラと丸い車体後端、A3のかさ上げされたキューポラ・後部ルーバー・砲塔バスケットが識別点。対象車両ごとに、上面・側面・背面で目に入りやすい特徴を選んで造形する。

## 実車写真から4面図を作る

1. 対象IDを [車両カタログ](../../../Assets/Modern8bitTanks/Resources/Data/vehicles_catalog.json) で確認する。現行の車体・砲塔を正面寄り、側面、背面寄りで見て、更新したいシルエットや識別点を絞る。試作型や年式違いがある場合は、採用した仕様を記録する。
2. 実車写真で特徴を確認する。車体と砲塔の輪郭、転輪の数と間隔、スカート、屋根上のハッチや照準器、後部グリルなど、ゲーム内の解像度で読める特徴を優先する。型式を確認できる資料や展示写真を使い、参照元を記録する。
3. 新たな原画が必要なら、使える場合は imagegen スキルを使う。実車写真を外観の参照にして、**上面・真横・正面・背面**を同じ車両のフォトリアルな正投影として生成する。上面と側面で車首の向きを揃え、各面で車体の比率と砲塔の向きを揃える。背景は単色、光は拡散光とし、画面内に車体と砲身の全体を入れる。構図は [T-14 Armata の4面原画](../../../Tools/VehicleArt/t14-armata-four-views.png) を参照する。
4. 原画を確認する。面ごとに転輪の数、砲塔の形、砲身の向きや長さなどが食い違う場合は、実車写真を根拠に生成結果を選び直すか、グリッドへの登録時に補正する。採用した写実4面図を [Tools/VehicleArt](../../../Tools/VehicleArt/) に保存する。画像生成や確認までの依頼なら、指定された段階で成果を渡す。

## 4面図からスライスを作る

1. [T-14 の変換実装](../../../Tools/armata_four_views.py) を参照する。原画の上面・側面・正面・背面を、車体と砲塔それぞれの同じグリッドに登録する。原画ごとに切り出し位置と縮尺を合わせ、輪郭の交差からボクセルを作る。必要な色を原画から取り、輪郭、足回り、装備の形をピクセル単位で整える。T-14 の座標と輪郭はその原画専用。
2. [既存の生成スクリプト](../../../Tools/refine_vehicle_sprites.py) の `MODELS` と出力形式に合わせる。各 PNG は同じ大きさの RGBA スライスを地面側から上へ並べた横一列のシートで、PNG 上は下向きが車首。砲塔は旋回軸をシートの中心に置く。PNG の幅は `Width × Slices`、高さは `Length` に合わせる。カタログの `hullBaseHeight` と `hullPivotOffsetY` で車体に砲塔を載せ、`muzzleDist` と必要な場合の `muzzleHeight` で砲口の表示位置を合わせる。既定の砲口高は砲塔ベースから2スライス。
3. リポジトリのルートで Python 3 と Pillow を使い、別フォルダーへ生成する。

   ```text
   python -B Tools/refine_vehicle_sprites.py --output-dir <ステージ先>
   ```

4. 前後のプレビューを同じ縮尺で作り、正面寄り・側面・背面寄りと、回転時の見え方を確認する。砲身の途切れ、砲塔の浮き、足回りのつぶれや砲口位置のずれを直す。ステージ内の PNG とカタログの寸法・スライス数を照合する。
5. `Assets/Modern8bitTanks/Resources/Vehicles/` に対象車両の `<id>_hull_slices.png` と `<id>_turret_slices.png` を反映し、対応するカタログ項目を更新する。既存車両では `.meta` の GUID、ID、依頼範囲外の車両や性能値を保つ。生成コマンドは対応車両をまとめて出力するため、ステージを比較して対象車両の差分を取り込む。

## Unity で仕上げる

- Unity スキルを使い、読み込み、Point フィルター、スライス数を確認する。Play モードでは格納庫で対象を選んで砲塔と車体の表示を確かめ、そのまま戦闘シーンに入って同じ車両の表示と砲口位置を確認する。稼働中のエディターを操作する場合は、選択・シーン遷移・確認を短い呼び出しに分け、シーンが切り替わってから検査する。
- 格納庫の拡大表示では回転中のシルエットを、戦闘の通常倍率では主要な素材の明暗差と型式の識別点を確認する。縮尺と角度を揃えた比較で、M48の品質基準と見比べる。
- 対象を反映した後、再生成結果とプロジェクトに取り込んだ素材を照合し、対象外の車両に差分がないことを確認する。採用型式、写実4面図、前後比較、参照元と試験結果を渡し、確認できなかった表示があれば明記する。
